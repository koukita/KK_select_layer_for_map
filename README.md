# KK_select_layer_for_map

地図キャンバス上でクリックした場所に存在するレイヤを、レイヤパネルで選択するQGISプラグインです。
複数のレイヤに地物が重なっている場合は、候補をメニューから選択できます。

## 対応環境

- QGIS 3.22 以上
- QGIS 4.x

## インストール

1. リポジトリ内の [`インストール用ZIP/KK_select_layer_for_map_0.9.1.zip`](インストール用ZIP/KK_select_layer_for_map_0.9.1.zip) をダウンロードします。
2. QGISのメニューから **プラグイン** > **プラグインの管理とインストール** を開きます。
3. **ZIPからインストール** を選択し、ダウンロードしたZIPファイルを指定します。
4. プラグインを有効にします。

## ボタンと機能

プラグインを有効にすると、QGIS上部の専用ツールバーにアイコンボタンが表示されます。

### 「マップ上でレイヤを選択」ボタン

![プラグインアイコン](plugins/KK_select_layer_for_map/icon.svg)

- ボタンを押すと、地図キャンバス上のレイヤ選択モードになります。
- ボタンが押された状態では、地図キャンバス上のポインターが十字形になります。
- ボタンをもう一度押すか、別のマップツールを選ぶと、レイヤ選択モードを終了します。
- プラグインを無効にすると、ボタンと専用ツールバーが削除されます。

## 使用方法

1. 地図キャンバス上のツールバーから「マップ上でレイヤを選択」ボタンを押します。
2. 選択したい地物がある場所を、マウスの左ボタンでクリックします。
3. 候補レイヤの数に応じて、次のように動作します。
   - 候補が1つの場合: レイヤパネル上でそのレイヤを選択します。
   - 候補が複数の場合: クリック位置の近くにレイヤ選択メニューを表示します。
4. メニューからレイヤ名を選ぶと、レイヤパネル上で該当レイヤを選択します。

右クリックや、左ボタン以外の操作ではレイヤ選択は実行されません。

## レイヤ選択時の動作

- 同じレイヤに複数の地物が重なっていても、候補には1回だけ表示されます。
- 選択したレイヤがグループ内にある場合は、親グループを展開します。
- レイヤパネル上で選択したレイヤまでスクロールします。
- レイヤパネルで凡例アイコンを表示できるレイヤでは、選択メニューにも凡例アイコンを表示します。
- レイヤパネル上で非表示になっているレイヤは、メニュー名の末尾に「（非表示）」と表示されます。
- レイヤの表示設定にかかわらず、プロジェクト内の有効なレイヤを候補として確認します。

## 注意事項

- ポイントレイヤ、ラインレイヤ、ポリゴンレイヤなど、地物を識別できるレイヤが対象です。
- レイヤ選択モードでは、通常の地図操作ツールには切り替わらず、クリックした地点の識別を優先します。
